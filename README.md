# Trick Plus – Расширение для Chrome

**Trick Plus** (ранее Pulse Plus / Pulse Fix) – внутреннее расширение для браузера Chrome, предназначенное для улучшения работы с сервисом Pulse. Расширение не публикуется в официальном магазине Chrome, поэтому установка и обновление выполняются вручную через CRX-файл и собственный сервер обновлений.

> Имена файлов на сервере обновлений (`pulse-fix.crx`, каталог `/extensions/pulse-fix/`) и ID расширения остались прежними — их переименование потребует одновременной правки на сервере и переустановки у всех пользователей.

---

## 📦 Установка расширения

1. **Скачать CRX-файл**  
   Файл расширения `pulse-fix.crx` доступен на сервере: https://vpn.sk-serv.ru:9443/extensions/pulse-fix/pulse-fix.crx

2. **Открыть страницу расширений Chrome**
- Перейдите в `chrome://extensions/`
- Включите **Режим разработчика** (Developer mode) в правом верхнем углу.

3. **Установить расширение**
- Перетащите CRX-файл в окно расширений Chrome.
- Подтвердите установку в появившемся диалоговом окне.

4. **Проверка установки**
- После установки иконка расширения появится справа от адресной строки.
- Версия расширения отображается при наведении на иконку.

---

## 🔄 Обновление расширения

Расширение обновляется **автоматически** с сервера обновлений, если появляется новая версия.

1. **Как Chrome узнаёт о новой версии**
- Расширение подключается к файлу `update.xml` на сервере:
  ```
  https://vpn.sk-serv.ru/extensions/pulse-fix/update.xml
  ```
- В этом файле указывается последняя версия расширения и ссылка на CRX-файл.
- Chrome периодически проверяет `update.xml` и, если версия отличается от установленной, выполняет обновление.

2. **Ручная проверка обновлений**
- Перейдите в `chrome://extensions/`
- Нажмите кнопку **Обновить** (Update) в режиме разработчика.
- Chrome скачает новую версию расширения, если она доступна на сервере.

## ⚙ Структура серверных файлов

На сервере файлы должны находиться так:
```
/extensions/pulse-fix/
├── update.xml
├── pulse-fix.crx
```

- **update.xml** — обязательный для автоматических обновлений.
- **pulse-fix.crx** — файл самой новой версии.

## ℹ Рекомендации

- При проблемах с обновлением можно вручную переустановить расширение через CRX.
